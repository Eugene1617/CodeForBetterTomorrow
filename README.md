# 💙 Titukulane

**Titukulane** is a modern fintech platform designed to promote financial inclusion by helping individuals, groups, and communities manage and grow their finances together. The name **Titukulane** means **"Let's Help Each Other"**, reflecting the platform's mission of collaboration, trust, and shared financial growth.

---

## 🌟 Features

- 🔐 Secure user authentication
- 👥 Group creation and management
- 💰 Savings and contribution tracking
- 📊 Financial analytics and visual dashboards
- 🔔 Notifications and reminders
- 📱 Responsive design for mobile and desktop
- 📈 Transaction history and reports
- 🤝 Member invitation and approval system
- 🌍 Clean, modern, and user-friendly interface

---

## 🎯 Mission

To empower individuals and communities with accessible digital financial tools that encourage saving, transparency, accountability, and collective economic growth.

## 🛠 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/titukulane.git
```

Move into the project

```bash
cd titukulane
```

Install backend dependencies

```bash
pip install -r requirements.txt
```

Run the backend

```bash
uvicorn main:app --reload
```

Open the frontend

```
frontend/index.html
```
